### 绕过代理设置

- 设置 -> 系统代理齿轮图标 -> 取消勾选 始终使用默认绕过 -> 填写代理绕过设置

### 公司限制访问网络

- ssh云服务器代理

```shell
ssh -D 1080 root@1.1.1.1 -p 22
```

1. 浏览器插件

```shell
# chrome下载插件 SwitchyOmega (V3)
选择代理服务器模式
填入: HTTP 127.0.0.1 1080
```

2. chash配置 , 新建订阅, 类型选择Local, 编辑文件, 填入以下信息

```shell
# Profile Template for Clash Verge

proxies: 
 - name: My-SSH-Tunnel
   type: socks5
   server: 127.0.0.1
   port: 1080

proxy-groups: 
  - name: "PROXY1"
    type: select
    proxies:
      - "My-SSH-Tunnel"
      - "DIRECT"

rules: 
  - MATCH,PROXY1

dns:
  enable: true                   # 开启 DNS 解析
  listen: 0.0.0.0:53            # DNS 监听地址（可选）
  enhanced-mode: fake-ip        # 推荐使用 Fake-IP 模式，对代理兼容性最好
  fake-ip-range: 198.18.0.1/16  # Fake-IP 范围
  nameserver:
    - 8.8.8.8                   # 使用 Google DNS 进行查询
    - 1.1.1.1                   # 或 Cloudflare DNS
  fallback:                     # fallback 服务器
    - tls://8.8.8.8:853
    - tls://1.1.1.1:853
```

- 反向代理端口

```shell
# 暴露端口给公网服务器 且保活
ssh -R 8089:127.0.0.1:8089 root@1.1.1.1 -o ServerAliveInterval=60 -o ServerAliveCountMax=3
```
