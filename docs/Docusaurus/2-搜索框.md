## 本地搜索框

```
1.安装
npm install --save @easyops-cn/docusaurus-search-local

2.docusaurus.config.js 增加配置
themes: [
  [
    '@easyops-cn/docusaurus-search-local',
    {
      hashed: true,
      language: ['en', 'zh'],
      highlightSearchTermsOnTargetPage: true,
      fuzzyMatchingDistance: 0,
    },
  ],
],

3.修改文件后需要build才能查询到最新的
npm run build
npm run serve
```
